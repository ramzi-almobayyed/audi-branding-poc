# audi-branding-poc

This repository contains a simple password-protected static page for an Audi branding concept preview.

Password:
- `AudiLogoPOC`

How to use GitHub Pages:
1. Open the repository in GitHub.
2. Go to Settings > Pages.
3. Under "Source", choose "Deploy from a branch".
4. Select the `main` branch and root folder `/`.
5. Save.
6. GitHub will provide a live Pages URL.

This is a front-end password gate only, so it is suitable for a lightweight demo but not as a secure backend-protected site.
